Backend continuation pack
========================
- Shared API bootstrap (CORS/security/requestId) on auth, tts, cambridge, push, jsonbin
- GET /api/jsonbin?scope=health
- Audit JSON logs for admin accountStatus / accountDelete
- Rate limits on tts + cambridge
- docs/ROADMAP.md for what to do next (client)

Copy over project root, deploy, then open:
  https://YOUR_DOMAIN/api/jsonbin?scope=health
Expect: { ok:true, supabase:true, redis:true/false, ... }
