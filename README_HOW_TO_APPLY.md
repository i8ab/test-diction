# الملفات المعدّلة فقط – Bacaloria v1.1.6

انسخ الملفات فوق مشروعك الحالي كالتالي:

| الملف | المسار في مشروعك |
|-------|------------------|
| index.html | جذر المشروع (استبدل) |
| package.json | جذر المشروع (استبدل) |
| sw.js | public/sw.js (استبدل) |
| public/fonts/* | public/fonts/ (أنشئ المجلد إن لم يكن موجوداً وانسخ كل الملفات) |
| OPTIMIZATION_BANDWIDTH.md | اختياري |

بعد النسخ شغّل:
npm run build
npm run preview

ثم اختبر: الخطوط العربية، الثيمات، القاموس، الـ PWA، الصوتيات.
