# عزل الإجراءات الصارم — قواعد الجلب والكتابة

## المبدأ
كل إجراء / صفحة / مكون يطلب **فقط** البيانات المرتبطة بوظيفته المباشرة.
لا جلب مسبق، ولا بيانات لمكونات أخرى، ولا payload زائد.

## دوال الجلب المجزأة (`cloudApi.js`)

| الدالة | الاستخدام |
|--------|----------|
| `fetchBootstrap()` | إعدادات عامة عند بدء التطبيق (بانر + امتحان + وحدات) |
| `fetchMyAccount(code)` | حساب المستخدم الحالي فقط |
| `fetchEntriesOnly()` | كلمات القاموس |
| `fetchAccountsOnly()` | قائمة الحسابات — **أدمن فقط** |
| `fetchLogsOnly()` | سجل النشاط — **أدمن فقط** |
| `fetchSettings(keys)` | مفاتيح إعدادات محددة |
| `fetchVersionOnly()` | رقم الإصدار فقط |
| `fetchRecord()` | السجل الكامل — **تجنب** إلا في مسارات الترحيل/التعارض النادرة |

## Hooks المستقلة (`src/lib/hooks/`)

| Hook | متى يُستخدم |
|------|-------------|
| `useExamConfig` | شاشات/مودالات الامتحان |
| `useAcademicUnits` | قسم الأكاديمي وإدارة الوحدات |
| `useAdminAccounts` | لوحة الإدارة فقط (`enabled` يحمي من الجلب العشوائي) |
| `useCloudEntries` | أي مكون يحتاج entries بمعزل عن App |
| `useStudyReminders` | تذكيرات الدراسة (موجود مسبقاً) |

## قواعد الكتابة
اتبع `partialSave.js`:
- `accountPatch` لحقل واحد في حساب
- `entryPatch` / `entryDelete` لكلمة واحدة
- `settingsPatch` لمفتاح إعدادات واحد
- `saveRecord` الكامل فقط للعمليات الجماعية النادرة

## ما يبقى في App
- حالة المصادقة (`authStage`, `accountCode`, `isAdmin`…)
- الجلسة والخزنة
- تنسيق الحفظ والطوابير (cloud queue / flush)
- البيانات اللي تظهر في الشريط الرئيسي (بانر، عدّاد امتحان) عبر bootstrap

## كاش قصير المدى (مرحلة 4)
كل نطاق له TTL مستقل في الذاكرة (نفس التبويب فقط):

| النطاق | TTL |
|--------|-----|
| bootstrap | 30 ث |
| account | 20 ث |
| accounts | 15 ث |
| entries | 45 ث |
| logs | 15 ث |
| settings | 30 ث |
| version | 10 ث |

- أي كتابة ناجحة تُفرّغ الكاش المجزأ تلقائياً.
- يمكن فرض التحديث بـ `{ fresh: true }`.

## ما لا يجب أن يحدث
- استدعاء `fetchRecord` في مسار المستخدم العادي
- تحميل كل الحسابات لمستخدم غير أدمن
- تحميل اللوجات قبل فتح لوحة الإدارة
- Prop drilling لبيانات يمكن للمكون جلبها بنفسه
- جلب مسبق لبيانات ميزة لم تُفتح بعد
